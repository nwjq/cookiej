# Release 文案模板

在 GitHub 创建 Release 时参考以下格式：

---

**标题**: CookieJ v{版本号}

**内容**:

```markdown
## CookieJ v{版本号}

### 更新内容 / What's Changed

#### 新功能
- 功能描述

#### 修复
- 修复描述

#### 改进
- 改进描述

### 升级说明 / Upgrade Notes

如有需要特别注意的事项在此说明。

### 下载 / Download

- [APK 下载](附件链接)

### 致谢 / Acknowledgments

感谢以下贡献者：
- @contributor
```
